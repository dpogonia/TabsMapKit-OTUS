# Tabs

Три вкладки на SwiftUI. Учебный проект OTUS.

Первая вкладка открывает вторую и сразу показывает случайное животное. На второй список: собака, кошка, заяц, черепаха и божья коровка. По нажатию открывается его значок. Третья вкладка показывает модальный экран с картой MapKit и меткой.

## Стек

SwiftUI, MapKit.

## Запуск

```bash
git clone https://github.com/dpogonia/TabsMapKit-OTUS.git
cd TabsMapKit-OTUS
open OTUSLesson1.xcodeproj
```

Запустите схему **OTUSLesson1** на симуляторе iPhone.
