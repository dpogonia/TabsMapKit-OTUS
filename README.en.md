# Tabs

Three tabs in SwiftUI. An OTUS study project.

The first tab opens the second one and shows a random animal right away. The second tab is a list: dog, cat, hare, tortoise, and ladybug. A tap opens its symbol. The third tab presents a modal screen with a MapKit map and a pin.

## Stack

SwiftUI, MapKit.

## Run

```bash
git clone https://github.com/dpogonia/TabsOTUS.git
cd TabsOTUS
open OTUSLesson1.xcodeproj
```

Run the **OTUSLesson1** scheme on an iPhone simulator.
